# kanon のテスト

Playwright（Chromium）で kanon を実際に開いて、画面と計算を確かめます。
`index.html` を直したら、push する前にここを走らせてください。

## 走らせ方

```bash
bash tests/run.sh
```

リポジトリの `index.html` を試します。全部で25本・約380項目。5分ほどかかります。

作業用のコピーを試すときは

```bash
KANON=/home/claude/app.html bash tests/run.sh
```

1本だけなら

```bash
python3 tests/t24.py
```

画面写真は `tests/_shots/` に出ます（git には入れていません）。

## 必要なもの

Python の playwright と Chromium。この環境には最初から入っています。
入っていなければ `pip install playwright && playwright install chromium`。

## 何を見ているか

| | 中身 |
|---|---|
| smoke | 開いて主要な画面が出るか |
| t_lot | FIFOの在庫計算（先に出した分から売れていく） |
| t2〜t11 | 出荷・販売・回収・直販・経費・作型・集計・CSV |
| t13〜t17 | バックアップと復元、完了の取り消し、まとめ出荷、毎日の作業 |
| t18 | 売上メールの取り込み（累積・差分） |
| t19 | PWA（オフラインで開けるか） |
| t20 | 「使う機能」で作業をオフにしたとき、一覧とカレンダーからも消えるか |
| t21 | **消えたトーストの「取り消す」が、見えないまま押せないか** |
| t22 | 「話して入力」を外したあと、出荷がいままでどおり動くか |
| t23 | 新しい版に入れ替わるか（サービスワーカーの更新） |
| t24 | 経費の貼り付け（マークダウン表・合計の検算・科目の警告・改行が消えた場合） |
| t25 | 追加した4科目（雇人費・利子割引料・土地改良費・素畜費）と旧名の移行 |

## 直すときに気をつけること

- **t21 は実際に起きた事故の再発防止です。** 消えたトーストの「取り消す」ボタンに
  当たり判定が残っていて、見えないまま押すと直前の記録が消えていました。
  画面下に居座るものを足すときは、必ずここを確かめてください
- **t24 の「お願い文の例をそのまま読み取れるか」** は、画面の説明文と
  実際の読み取り処理が食い違わないようにするためのものです。
  お願い文を変えたら、例も一緒に直してください
- **t23 は版の文字列を `sw.js` から読みます。** 版を上げてもテストは直さなくて大丈夫です

## 新しいテストを足すとき

既存のものをコピーして作ってください。先頭のおまじない（ROOT／APPURL／OUTDIR）を
そのまま残せば、どこに置いても動きます。最後に `tests/run.sh` の一覧にも名前を足してください。
