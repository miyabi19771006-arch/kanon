# kanon

農を奏でる記録アプリ。出荷・売上・作業・防除・収穫・経費をひとつにまとめる、個人農家のための記録アプリです。

- 依存ライブラリなし、ビルドなし。静的ファイルを置くだけで動きます。
- 記録は**端末の中（localStorage）にだけ**保存されます。サーバーには送りません。
- 圏外でも開けます（Service Worker）。

## 置き方（GitHub Pages）

1. このリポジトリの中身を、リポジトリの**直下**に置く。
2. Settings → Pages → Build and deployment → Source を **Deploy from a branch**、Branch を **main / (root)** にして Save。
3. 1〜2分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が開きます。
4. スマホでそのURLを開き、ホーム画面に追加する。
   - iPhone：Safari で開く → 共有ボタン → 「ホーム画面に追加」
   - Android：Chrome で開く → ︙ → 「ホーム画面に追加」

**リポジトリは public にしてください。** 無料アカウントでは private リポジトリの Pages が使えません。
公開されるのはプログラムだけで、記録は公開されません。

## 大事なこと

- **URLのうち `https://<ユーザー名>.github.io` の部分は変えない。** 記録はこの部分にひもづいて保存されます。
  リポジトリ名（パス）は変えても記録は残りますが、独自ドメインに移すと記録は引き継がれません。
- **月に一度、設定タブの「全データを保存（JSON）」でバックアップを取る。** 30日を過ぎると予定タブが催促します。
  端末が壊れたとき、機種変更のとき、ブラウザのデータを消したときは、このファイルからしか戻せません。

## 更新のしかた

1. `index.html` を差し替える。
2. `sw.js` の1行目あたりにある `const V = 'kanon-YYYY-MM-DD';` の日付を**必ず新しくする**。
   ここを変えないと、古いものが端末に残り続けて更新が届きません。
3. push する。次にアプリを開いたとき「新しいkanonがあります」と出ます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。これ1つでも動きます |
| `sw.js` | 圏外でも開けるようにする仕組み |
| `manifest.webmanifest` | ホーム画面に入れたときの名前・色・全画面設定 |
| `icon-192.png` / `icon-512.png` | Android・ブラウザ用アイコン |
| `apple-touch-icon.png` | iPhone用アイコン |
